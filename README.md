# Connector Challenge

Juego educativo en español para practicar cómo identificar los conectores y componentes de una placa base. Es un sitio estático.

## Modos y datos

Incluye práctica individual, duelo por turnos en el mismo dispositivo y contrarreloj. Los récords y el progreso se guardan en el navegador de cada persona; no se comparten ni sincronizan entre dispositivos. Publicar el juego crea un enlace para abrirlo, pero no conecta a varias personas en una partida online.
